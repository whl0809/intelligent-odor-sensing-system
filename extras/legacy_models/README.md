# Legacy model experiments

These files are preserved for historical reference and are not part of the
supported training or test workflow.

- `tgs_mcp3421/` uses TGS plus NH3/H2S data and an incompatible artifact
  contract.
- `tgs_svm41_alternative/` is an earlier alternative TGS + SVM41 trainer.

The active format-version 2 trainer and matching test runner are in `model/`.
